# 🎨 디자인 시스템 명세서 (Design System Specification)

본 문서는 **초등 문해력 스마트 코스웨어**의 시각 언어(Visual Language), UI 토큰, 3D 물리 인터랙션 규칙 및 아토믹 컴포넌트 변형(Variants)을 상세히 규정합니다.

---

## 1. 디자인 철학 및 3대 핵심 기둥

```
   ┌─────────────────────────────────────────────────────────────┐
   │                       문해력 LMS 디자인 시스템               │
   └──────────────────────────────┬──────────────────────────────┘
                                  │
       ┌──────────────────────────┼──────────────────────────┐
       ▼                          ▼                          ▼
[ 에디토리얼 서재 조판 ]   [ Brilliant 3D 키캡 인터랙션 ]  [ Tremor 고대비 매트릭스 ]
   • 활판 인쇄 활자 세리프      • 3px 볼록 물리적 키캡 그림자   • 상단 3px 컬러 인디케이터
   • 웜 페이퍼 질감 캔버스      • 1.5px 실제 눌림 물리 피드백   • 고가독성 모노 수치 그리드
   • 다크 로열 네이비 잉크      • 출판 검수 도장 스탬프 배지    • 6대 역량 방사형 분석 차트
```

### 왜 흔한 AI 스타일(보라 그라데이션)을 버렸는가?
- 보라/인디고 그라데이션과 옅은 파스텔 카드는 AI가 무작위로 생성한 템플릿의 대표적인 클리셰이며, 집중력을 산만하게 만듭니다.
- 초등 5·6학년 학생들에게는 **"종이책을 실제로 펼쳐놓고 연필을 쥐고 정독하는 듯한 아날로그 서재의 차분함"**과 **"손끝으로 키캡을 눌렀을 때 즉각 반응하는 물리적 재미(Brilliant 3D)"**가 훨씬 높은 학습 몰입도를 유발합니다.

## 3. 타이포그래피 조판 규칙 (Typography)

웹 폰트로 `Noto Serif KR`과 `Pretendard / Inter`를 조합하여 최적의 에디토리얼 가독성을 구현합니다.

### 클래스 명세
- `editorial-serif`:
  - `font-family: 'Noto Serif KR', Georgia, serif;`
  - 지문 제목, 문단 본문, 시험 문제 문두에 적용되어 활판 인쇄의 품격을 부여합니다.
- `editorial-para`:
  - `font-size: 1rem (16px) ~ 1.125rem (18px)`
  - `line-height: 2.15 ~ 2.35`
  - 초등학생이 긴 글을 읽을 때 줄을 놓치지 않도록 넓고 쾌적한 행간을 제공합니다.
- `font-mono`:
  - 숫자, 점수, 회차, 타임스탬프에 적용하여 Tremor 스타일의 데이터 정렬미를 극대화합니다.

## 4. 3D 물리 인터랙션 토큰 (Tactile & Shadows)

### 그림자 토큰 규격
```css
/* Tailwind 커스텀 유틸리티 */
.shadow-tactile {
  box-shadow: 0 3px 0 0 #0F172A;
}

.shadow-tactile-sm {
  box-shadow: 0 2px 0 0 #0F172A;
}

.shadow-card {
  box-shadow: 0 4px 20px rgba(15, 23, 42, 0.05);
}
```

### 물리적 클릭(눌림) 반응
버튼이나 선택지를 클릭(`:active`)했을 때 그림자 높이만큼 수직으로 내려앉는 인터랙션을 제공합니다:
```css
.active-tactile:active {
  transform: translateY(1.5px);
  box-shadow: 0 1.5px 0 0 #0F172A;
}
```

## 5. 핵심 아토믹 컴포넌트 규격 (Core UI Components)

| :--- | :--- | :--- |
| `tactile` | 다크 잉크(#0F172A) 배경 + 3D 그림자 + 볼록 피드백 | 대시보드 복습, 지문 전환, 모달 확인 등 |
| `tactile-emerald` | 포레스트 에메랄드(#059669) 배경 + 3D 그림자 | 시험 시작, 과제 일괄 배정 등 핵심 액션(CTA) |

| `editorial` | 웜 페이퍼(#FAF8F5) 배경 + 2px 다크 잉크 테두리 | 지문 정독 완료, 이전 단계 등 보조 액션 |
| `outline` | 투명 배경 + 2px 회색 테두리 + 호버 시 잉크 전환 | 모달 닫기, 보조 옵션 토글 |

## 6. 특수 인터랙션 가이드라인

1. **키보드 단축키 연동 (Keyboard 1~5 Keycaps):**
   - 시험 응시 화면(`TakeTest.tsx`)에서 학생이 키보드 `1`, `2`, `3`, `4`, `5` 키를 누르면 즉시 해당 3D 키캡 선택지가 물리적으로 눌리며 정답이 선택됩니다.
2. **3D 플래시카드 뒤집기 (Flip Flashcards):**
   - 어휘 수첩(`VocabularyList.tsx`)에서 카드를 클릭하면 CSS 3D 트랜스폼(`rotate-y-180`)을 통해 앞면(웜 페이퍼 캔버스)에서 뒷면(다크 잉크 앰버)으로 부드럽게 뒤집힙니다.
