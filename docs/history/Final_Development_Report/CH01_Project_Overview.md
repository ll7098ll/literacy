# [제1장] 프로젝트 개요 및 방법론 (Project Overview & Methodology)

## 1. 프로젝트 헌장 (Project Charter)
*   **프로젝트 공식 명칭**: AI 기반 문해력 평가 및 인터랙티브 학습 시스템 (Interactive Literacy Evaluation AI System)
*   **개발 목표**: 사용자의 학년과 관심사에 맞춘 지문을 동적으로 생성하고, 독해 과정에 실시간으로 개입하는 AI 튜터 기반의 교육용 플랫폼 구축. 완전한 인터랙션과 수학적/논리적 도식(SVG)의 무결함 렌더링 목표.

## 2. 개발 방법론: 하이퍼 워터폴 (Hyper-Waterfall)
애자일(Agile)의 속도와 워터폴(Waterfall)의 엄격함을 합친 극한의 엔지니어링 기록 체계입니다.
*   **핵심 철학**: "문서화되지 않은 코드는 존재 가치가 없다."
*   **실행 원칙**: 
    1.  모든 요구사항의 마이크로 분리 (엣지 케이스조차 요구사항으로 명시)
    2.  에러 발생 시 즉각적인 핫픽스를 넘어서는 "근본 원인 분석(RCA)" 문서화 의무화
    3.  프롬프트, 컴포넌트 생명주기, CSS 속성 단 하나까지 설계 의도 명세.

## 3. 핵심 비즈니스 가치 (Business Value)
본 프로젝트는 기존의 정적인 문제 풀이 앱을 넘어섭니다. AI가 학생의 응답을 문단 단위로 추적하고, 문맥에 맞는 단어 사전(`explainWordInContext`)을 즉시 팝업하며, '왜 이 답이 틀렸는지' 대화형으로 코치하는 데 가치가 존재합니다. 완전히 반응형으로 제공되는 시각적 다이어그램(SVG) 기능은 어떠한 과목(수학, 과학, 논리) 지문에도 확장 가능한 범용성을 부여합니다.
