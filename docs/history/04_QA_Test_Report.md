## 3. 남은 기술적 부채 (Technical Debt) 및 넥스트 스텝
1.  **SVG 내부 폰트 최적화**: 현재 SVG 내 `<text>` 태그 폰트가 OS 기본 폰트를 따라갈 수 있으므로, Tailwind 등 글로벌 폰트(`font-sans`)를 상속받도록 SVG 렌더러 단에서 속성 주입 필요성 고려.
2.  **LLM 응답 지연(Latency) 개선**: 긴 지문을 로딩하고 해설을 동기(Synchronous) 방식으로 받아올 때 대기 시간 최적화 (스트리밍 방식 적극 반영 고려).
